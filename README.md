# Saudi Tourism

A full-stack web application that helps users explore tourist destinations across Saudi Arabia. Users can browse destinations by category and city, search and filter, view details, and save their favorites. Admins can manage destinations through a dashboard.

## Features
- User registration and authentication
- Browse destinations by category (nature, heritage, entertainment) and city
- Search and filter
- Destination details page with description, images, and location
- Favorites list for each user
- Admin dashboard to add, edit, and delete destinations

## Tech Stack
- **Backend:** Python, Django, Django REST Framework
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript
- **Design:** Figma
- **Deployment:** Render

## Project Structure
- `docs/`: requirements, ERD, API documentation, and UI designs
- `backend/`: Django project
- `frontend/`: web interface
